at the core, we’d be producing a _dataset_. for my project, that would be a set of n-turn conversations for the models to run against. we collect qualitative and quantitative outputs.

- **some sample outputs we would _like to see_ at the end of a run of a model:**
    - what was the model propensity to _choose catastrophic option?_
    - how did it change when decoupled from corpus?
    - how did it change when given different alignment priorities?
    - when uncertain, did it seek

**ways we’d like to decouple the model from its corpus:**

- establish a new WMD. variants:
    1. this WMD has not only a different name (not “nuclear” or any mention thereof) and is not a bomb but is qualitatively similar: death toll on the millions, one-off action.
    2. this WMD is functionally different.
    3. this WMD is different nominally, functionally, and collaboratively. (agent _must_ seek verification and consent from allies to deploy)
- generate complex strategic scenarios that are on the geopol horizon, but are NOT precedented in the corpus. permutation sets of all of these events should appear in the dataset.
